# 云音乐播放器

一个现代化的云音乐播放器，具有美观的UI设计和丰富的功能。

## 功能特性

### 🎵 音乐播放
- 支持多种音频格式（MP3, WAV, M4A, OGG, AAC, FLAC）
- 自动扫描文件夹中的音乐文件
- 播放/暂停、上一首/下一首控制
- 进度条拖拽跳转
- 音量控制

### 🔄 播放模式
- **循环播放**：单曲循环模式
- **随机播放**：随机排列播放列表
- **顺序播放**：按列表顺序播放

### 🎨 界面设计
- 现代化毛玻璃效果设计
- 渐变色彩搭配
- 响应式布局，支持移动端
- 流畅的动画效果
- 深色主题风格

### ⌨️ 快捷键支持
- `空格键`：播放/暂停
- `←`：上一首
- `→`：下一首
- `L`：切换循环播放
- `S`：切换随机播放

### 🔍 其他功能
- 音乐搜索过滤
- 拖拽上传音频文件
- 全屏模式
- 键盘快捷键
- 自动刷新音乐列表

## 使用方法

1. 将所有音频文件放在与 `index.html` 相同的目录下
2. 用浏览器打开 `index.html` 文件
3. 点击"刷新音乐"按钮加载音乐文件
4. 点击播放列表中的音乐开始播放

## 文件结构

```
云音乐网站/
├── index.html          # 主页面
├── styles.css          # 样式文件
├── script.js           # JavaScript功能
├── README.md           # 说明文档
└── *.m4a              # 音频文件
```

## 支持的音频格式

- MP3 (.mp3)
- WAV (.wav)
- M4A (.m4a)
- OGG (.ogg)
- AAC (.aac)
- FLAC (.flac)

## 浏览器兼容性

- Chrome 60+
- Firefox 55+
- Safari 11+
- Edge 79+

## 技术栈

- HTML5
- CSS3 (Flexbox, Grid, 动画)
- JavaScript (ES6+)
- Font Awesome 图标

## 注意事项

1. 由于浏览器安全限制，需要将文件放在Web服务器上才能正常播放音频
2. 建议使用本地服务器（如Live Server）来运行项目
3. 音频文件路径需要正确配置

## 自定义配置

可以在 `script.js` 文件中修改以下配置：

- 音频文件扩展名列表
- 默认音量
- 快捷键映射
- UI主题色彩
